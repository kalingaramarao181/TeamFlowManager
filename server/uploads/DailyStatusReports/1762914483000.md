# PLC Simulator

A Node.js simulator for orifice flow with wear state tracking, designed to run on Google Cloud Run.

## Features

- Simulates orifice flow dynamics with wear progression
- Tracks flow rate, temperature, wear level, and pressure differential
- Updates simulation state every 3 seconds
- RESTful API endpoints for simulation data and health checks

## API Endpoints

- `GET /sim` - Returns current simulation state:
  - `flowRate`: Current flow rate (m³/s)
  - `temperature`: Temperature (°F)
  - `wearLevel`: Current wear level
  - `deltaP`: Pressure differential (Pa)

- `GET /health` - Health check endpoint

## Local Development

```bash
cd plc-simulator
npm install
npm start
```

The server will start on port 8080 (or the port specified in the `PORT` environment variable).

## Deployment to Google Cloud Run

From the `plc-simulator` directory:

```bash
gcloud run deploy plc-sim \
  --source . \
  --region us-central1 \
  --allow-unauthenticated \
  --port 8080
```

After deployment, your service will be available at:
`https://plc-sim-xxx.run.app/sim`

## Prerequisites

- Google Cloud SDK installed and configured
- Docker (for local testing)
- Node.js 18+ (for local development)

## Testing Locally with Docker

```bash
docker build -t plc-simulator .
docker run -p 8080:8080 plc-simulator
```
